### Как добавить репозиторий
1. Откройте **Sileo** или **Zebra** на вашем iPhone.
2. Перейдите во вкладку **Источники** (Sources) и нажмите **`+`**.
3. Вставьте ссылку на репозиторий:
   ```text
   https://leafer95.github.io/leafer.github.io/
   ```
